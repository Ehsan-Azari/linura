# Support

Linura is pre-release software. Use GitHub issues for bugs, feature requests, and compatibility reports once hosted. Security issues follow `SECURITY.md` and must not be filed publicly.

A useful system compatibility report includes:
- distro and version;
- kernel;
- systemd version;
- compositor/session;
- relevant provider versions (NetworkManager, BlueZ, PipeWire, UDisks2, etc.);
- exact Linura commit/version;
- capability snapshot and sanitized logs.
