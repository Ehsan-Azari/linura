- workspace version/lockfile/release-contract coherence;

## Release authorization contract

Merging release preparation does not authorize publication. The later protected-main release authorization must be a metadata-only commit with exactly one parent: the reviewed release-preparation source. Its Git tree must be identical to the parent's tree, and its commit message must contain exactly one matching pair of trailers:

```text
Reviewed-Source: <immediate-parent-sha>
Reviewed-Tree: <identical-parent-and-source-tree-sha>
```

`tools/release_contract.py validate-intent` must validate that identity before proof dispatch and again inside Trusted Release Proof. No tracked file is modified to encode the reviewed tree, avoiding a self-referential tree hash.

## Protected publication gate

The tree-identical release-authorization source must then receive fresh protected-main CI, Security, CodeQL and all mandatory v0.4 qualification, including genuine ext4 ENOSPC and durability fault suites. Trusted Release Proof must validate intent, rerun mandatory qualification, build and independently reproduce the exact source, and seal the release evidence. Promotion must consume the sealed proven bytes without rebuilding. Publication is tag-last, and independent Release Verification must succeed from a fresh runner.

## Post-publication closure

Only after independent verification may a normal protected PR:

- advance `current_release` to `v0.4.0` and `next_release` to `v0.5.0`;
- mark the v0.4 milestone released and add final release/qualification pointers;
- update README from publication-pending to released;
- record exact release-intent, protected-main checks, Trusted Release Proof, promotion, immutable publication and Release Verification evidence;
- remove obsolete temporary v0.4 branches and closed qualification artifacts that are not required as durable evidence.

The post-publication closure must not alter the immutable v0.4 release contract/tag/assets or expand the no-executor/no-supported-external-mutation claim boundary.
