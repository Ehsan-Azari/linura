## Publication contract

After this release-preparation source is itself reviewed and green, publication requires a single-parent metadata-only `release: v0.5.0 — isolated privileged executor and independent verifier qualification` commit immediately above the reviewed source. That commit must have an identical tree and exactly record `Reviewed-Source` and `Reviewed-Tree` trailers.

Fresh protected-main CI/Security/CodeQL must pass on that exact authorization. Trusted Release Proof then reruns all mandatory exact-source VM/fault qualifications and sealed reproducible build before Release Promotion. Promotion must consume the proven payload without rebuilding; tag-last publication must create the immutable GitHub Release; an independent Release Verification must succeed before post-publication roadmap bookkeeping advances to v0.6.
