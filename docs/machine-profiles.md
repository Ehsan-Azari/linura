# Machine profiles, personality and replay

A machine profile is a portable set of **intent and constraints**, not a frozen list of package names.

Examples:
- AI development workstation
- distraction-minimized writing machine
- travel-security profile
- accessible high-contrast workstation

Export/replay should preserve intent and policy constraints while allowing the planner to select implementations appropriate to different hardware/platform profiles.

The user's machine "personality" is therefore an explainable composition of active intents/preferences, not hidden model memory.
