# Explainability contract

`Explain` is a core protocol operation, not model-generated storytelling.

For an intent/resource/capability Linura should eventually answer:
- Why does this exist?
- Which intent/requirement caused it?
- What depends on it?
- What does it depend on?
- Is it shared by other intents?
- What happens if I retire/remove it?
- What changed it most recently?
- Does observed state match desired state?
- What policy constrained it?

The protocol returns structured evidence; clients and agents may render a human explanation from that evidence.
